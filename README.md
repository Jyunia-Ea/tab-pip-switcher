# Tab PiP Studio · 标签页画中画切换器

基于 **Manifest V3** 与 **Document Picture-in-Picture API** 的 Chrome / Edge 扩展：
把任意标签页放进**常驻最顶层的画中画窗口**，用快捷键或按钮**来回切换标签页**，
适配**会议 / 录屏 / 演示 / 在线教学**等"需要电脑切屏"的场景。Windows 与 macOS 通用。

浏览器要求：**Chrome ≥ 116 / Edge ≥ 116**（Document PiP 的最低支持版本）。

---

## 一、它能做什么

| 场景                          | 做法                                                         |
| ----------------------------- | ------------------------------------------------------------ |
| 开会/录屏时想一直看到某页内容 | 把该页「镜像」或放进「画中画台」，窗口永远悬浮在最上层       |
| 需要来回切换标签页            | `Alt+Shift+← / →` 在标签顺序上前后切换；控制台/画中画窗口里也有按钮 |
| 切屏、切应用、切虚拟桌面      | 画中画窗口始终置顶；开启「跟随当前标签」后，它自动镜像你正在看的标签 |
| 演示时放大内容                | 直接用鼠标把画中画窗口**拖拽拉大**（规范禁用了窗口内全屏与程序化缩放，但允许用户手动拖拽） |

---

## 二、两种模式

### 模式 A：画中画台（默认，适合快速切换）

- 打开扩展**控制台页** → 点「启动画中画窗口」→ 画中画里出现 **工具条 + iframe 预览**。
- 切换标签 = 改 iframe，**瞬时完成**，原标签页完全不受影响。
- 工具条提供：`‹ 上一个 / 下拉选择 / 下一个 ›`、`跟随:开/关`、`×`。
- **跟随当前标签**：开会后点一下，你在浏览器里切到哪个标签，画中画就显示哪个——切屏场景的核心。
- 适合可被 iframe 嵌入的站点（绝大多数普通网页）。

### 模式 B：镜像模式（任何网站可用  ）

- 在每个网页**右下角**有一个「画中画」悬浮按钮（真实点击 = 规范要求的用户手势，最稳定）。
- 点击后，**当前标签的 DOM（连同样式）整体搬进画中画窗口**，视频继续播放、表单状态保留；
  对**禁止被 iframe 嵌入**的站点（X-Frame-Options / CSP frame-ancestors）同样有效。
- 镜像窗口顶部有工具条：`‹ 上一个 / 下一个 › / 返回标签 / ×`；源标签页内容会临时搬空，返回时原样移回（滚动位置也还原）。
- 适合：登录态页面、视频页、在线文档、仪表盘等。

> 重度动态页面（SPA 持续重绘 body）在镜像期间新产生的节点会回流到源标签——这是 DOM 搬运方案的固有限制，此时建议用模式 A。

## 三、安装（Chrome / Edge，Windows / macOS 步骤一致）

1. 解压 `tab-pip-switcher.zip`，得到 `tab-pip-switcher/` 文件夹。
2. Chrome：打开 `chrome://extensions`；Edge：打开 `edge://extensions`。
3. 打开右上角「**开发者模式**」开关。
4. 点击「**加载已解压的扩展程序**」，选择 `tab-pip-switcher/` 文件夹。
5. 完成后建议在扩展管理里把「站点访问权限」设为「在**所有站点**上」（默认即如此，用于内容脚本与嵌入检测）。

> 说明：扩展需要 `<all_urls>` 主机权限（悬浮按钮注入、判断站点能否被嵌入），Chrome 会显示相应权限提示，属正常现象。

## 四、使用与快捷键

| 快捷键        | 作用                                       |
| ------------- | ------------------------------------------ |
| `Alt+Shift+P` | 启动画中画台；已启动时切换「跟随当前标签」 |
| `Alt+Shift+←` | 画中画显示**上一个**标签                   |
| `Alt+Shift+→` | 画中画显示**下一个**标签                   |
| `Alt+Shift+Q` | 关闭画中画（镜像模式会把内容移回原标签）   |

macOS 上 `Alt` 即 `Option`，组合键相同。

### 标签页右键菜单

在任意标签页上**右键**，即可直接呼出画中画小窗：

| 菜单项                             | 作用                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| 在画中画小窗中显示此标签           | 自动启动画中画台并显示该标签（瞬时预览、原标签不受影响；站点禁止嵌入时显示标题面板，可改用下方「镜像」） |
| 镜像此标签到画中画（任何网站可用） | 把该标签内容整体搬进小窗（含禁止 iframe 嵌入的站点；源标签临时搬空，关闭后原样移回） |
| 关闭画中画                         | 关闭当前小窗（镜像模式自动把内容移回原标签）                 |

> 由 `chrome.contextMenus` 注册（`contexts: ["tab"]`），Chrome / Edge 通用；
> 「关闭画中画」在标签页、普通网页、扩展图标上右键也都可用。

其他入口：

- **工具栏图标（popup）**：打开控制台 / 启动画中画台 / 镜像当前标签 / 关闭画中画 / 跟随开关；并列出全部标签，可逐条「画中画台 / 镜像」。
- **控制台页**（点 popup 的「打开控制台」）：搜索标签、设置窗口尺寸、跟随开关、上/下一个。
- **页面右下角「画中画」按钮**：一键镜像当前页。

### 修改快捷键

Chrome / Edge 的 `chrome://extensions/shortcuts`（或 `edge://extensions/shortcuts`）里可以自定义，
例如避免与输入法切换、其他软件冲突（Windows 上 `Alt+Shift` 常见于输入法切换，建议改成 `Ctrl+Shift+…` 或 `Alt+1/2/3` 等）。

## 五、工作原理

```bash
┌───────────────────── 快捷键 / popup / 页面右下角悬浮按钮 ─────────────────────┐
│                                                                             │
│ 后台 Service Worker（统一状态机 + 编排，状态持久化 storage.session）           │
│   ├─ 入口：用户操作（点击悬浮按钮/快捷键/popup），携带合法 userGesture          │
│   ├─ 模式选择分支（可手动切换，也可自动判断站点特征自动选用）：                  │
│   │   ├─ 【模式A：Iframe Hub 模式（优先推荐）】                               │
│   │   │    → 打开/激活扩展控制台Hub页 → executeScript 注入                    │
│   │   │    → Hub页 requestWindow() 创建扩展同源PiP窗口                        │
│   │   │    → PiP窗口内承载顶部工具条 + <iframe src=目标标签URL>                │
│   │   │    → tabs.onActivated 监听，实现PiP跟随当前激活标签自动切换iframe地址  │
│   │   │    → 特点：DOM实时同步，SPA动态渲染正常；受 X-Frame-Options / CSP frame-ancestors 拦截限制
│   │   └─ 【模式B：DOM镜像搬运模式（兜底兼容，优化中，不推荐默认）】               │
│   │        → executeScript 注入内容脚本，捕获页面完整DOM、样式、滚动位、媒体/表单状态
│   │        → 将源页面body内节点迁移至内存，源标签临时清空内容                    │
│   │        → requestWindow() 创建扩展同源PiP镜像窗口，挂载顶部同款工具条         │
│   │        → 把取出的DOM+样式挂载进镜像窗口渲染，**不使用iframe**，绕过嵌入拦截
│   │        → 工具条：‹上一个/下一个› / 返回标签 / ×关闭；还原时DOM迁回源页，滚动位置复原 
│   │        → 局限：重度SPA持续重绘时，新增DOM节点只会出现在源标签，镜像窗口不同步   |
│   └─ 公共统一能力（A/B共用同一套工具条、标签切换、关闭、返回逻辑）                  │
└────────────────────────────────────────────────────────────────────────────────┘
```

关键实现细节：

- **用户手势（transient activation）**：`requestWindow()` 必须由真实点击触发。因此：
  - 最稳路径 = 页面悬浮按钮 / 控制台「启动」按钮的直接点击；
  - 快捷键路径 = 后台 `chrome.scripting.executeScript({ userGesture: true })` 尽力模拟；
    若个别浏览器版本判定不通过，会在控制台页提示"请直接点一次按钮"——属于规范设计使然，非缺陷。
- **PiP 窗口内禁用了 `requestFullscreen()`**（规范 6.13 明确规定），也禁用了无手势的 `resizeTo`，
  所以本扩展不提供程序化缩放，用户直接拖拽窗口即可（浏览器允许手动调整）。
- **嵌入检测**：控制台页用扩展主机权限对目标 URL 发 `HEAD` 请求，检查 `X-Frame-Options` / CSP `frame-ancestors`；
  检测失败时乐观放行，交给 iframe 实际表现；被禁止时显示"标题 + 在新标签打开 + 仍尝试嵌入"占位面板。

## 六、跨平台（Windows / macOS）注意事项

- 核心代码完全一致（Manifest V3 + Document PiP 均为跨平台 API），**同一份代码两种系统通用**。
- `Alt+Shift+←/→/P/Q` 在 Windows / macOS 均可用（macOS 上 Alt = Option）。
- 置顶行为：画中画窗口在**当前桌面/空间**内永远置顶；切换到另一个**虚拟桌面 / Mission Control 空间**时，
  画中画会留在原桌面（这是操作系统行为，不是扩展缺陷）。多显示器下画中画出现在浏览器所在屏幕，可用鼠标拖到目标屏。
- 会议软件（腾讯会议、Zoom、Teams、钉钉等）共享屏幕时，把画中画窗口拖到要展示的区域即可随画面共享。

## 七、已知限制

1. **镜像模式下源标签会被搬空**：期间该标签页面空白属正常；关闭/返回时内容移回。若浏览器崩溃或源标签被直接关闭，
   内容随 PiP 窗口销毁，无法找回（规范：PiP 窗口不活过打开者）。
2. **镜像模式对动态 SPA 不完美**：新渲染节点可能回流到源标签。
3. **画中画台无法嵌入禁止 iframe 的站点**：会显示标题占位面板；这类站点请用镜像模式。
4. **`chrome://` / 应用商店 / `file://` 页面**：内容脚本不注入，也无法嵌入，只能显示标题面板。
5. **画中画窗口内程序化全屏被规范禁用**：请手动拖拽调整大小。
6. `requestWindow()` 的**首次启动**必须有真实用户手势；快捷键首次启动为"尽力而为"，
   若被拒会在控制台页给出明确提示，点一下按钮即可。

## 九、问题排查

- **快捷键没反应**：确认 `chrome://extensions/shortcuts` 里已分配；与其他软件冲突时改绑。
- **画中画启动失败，提示需要手势**：直接在控制台页点「启动画中画窗口」，或点页面右下角「画中画」按钮。
- **某些站点在画中画里是标题面板**：该站点禁止被嵌入，改用「镜像」按钮。
- **想清空状态重来**：关闭画中画后，在 `chrome://extensions` 里点扩展的"重新加载"即可。
